# Project Portfolio | Wang Shuo

## Tiny:bit K210 Face Recognition Robot

### Goal
Build an educational robot that registers faces, recognises them later, displays the identity number on micro:bit and plays an assigned sound.

### System
Camera and K210 vision module perform detection and feature comparison. A serial message carries the identity index to micro:bit, which displays the number and selects a melody.

### Contribution
Individual project. Wang Shuo performed the Product Owner, Scrum Master and Developer responsibilities: prioritisation, sprint tracking, implementation, integration and project presentation.

### Technologies
Tiny:bit, micro:bit V2, K210, MicroPython, KPU models, MakeCode and serial communication.
