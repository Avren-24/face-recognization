# Project Robot2 Face Recognition

Tiny:bit robot using a K210 vision module and micro:bit feedback.

- `main.py`: K210 face registration, recognition, serial output and feature-signature routine.
- `k210/`, `KPU/`: example programs and required model files.
- `microbit/`: micro:bit firmware examples.
- `reports/`: editable report drafts and presentation.

The enrolled-face signature file `data.txt` is excluded because it contains derived biometric data. Do not commit face images or enrollment records. Review simulated planning examples and replace them with verified records before submission.
